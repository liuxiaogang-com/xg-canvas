## 1. 登录系统

打开 `http://localhost:5180`。空实例会先进入 `/setup`；填写管理员名称、邮箱和密码即可
创建首位 Owner，成功后会直接进入后台配置，无需准备 Token 或重启服务。

## 2. 配置模型渠道

进入 **设置 → Provider**，确认至少存在一个已启用的 Provider、渠道、凭证和模型。模型是否可用取决于部署者配置及对应厂商服务。

## 3. 创建项目

从项目列表创建一个项目。项目会成为画布、任务、成员和资产的归属范围。

## 4. 添加节点

进入项目画布后，添加文本、图像、视频、剧本或实体节点。连接必须满足节点端口的输入输出类型约束。

## 5. 执行并查看结果

选择可用模型并提交生成。任务会先持久化，再由任务运行器排队、轮询和重试。成功结果会进入项目资产库，并存入配置的 S3/R2 兼容存储。

下一步可以继续阅读[画布与节点](/docs/user-guide/canvas-and-nodes/)和[剧本与分镜](/docs/user-guide/storyboards/)。
