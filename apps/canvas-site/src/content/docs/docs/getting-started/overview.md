XG Canvas 用一张可持久化的节点画布连接企业创意项目中的脚本、角色、场景、道具、分镜、生成任务与最终资产，并把模型、权限、日志和成本纳入同一个治理边界。

企业真正缺的往往不是另一个生成入口，而是一套能把创作上下文、模型调用、权限、成本和资产归属连接起来的生产系统。

## 与通用创作 SaaS 的区别

XG Canvas 的核心组合是 **BYOK（企业自带模型凭证）+ 自托管 + 团队权限 + 可定制工作流**：

- 管理员连接企业自己的模型供应商账户，成员不共享厂商登录，也不接触原始 Key。
- 每位成员使用独立的平台身份，调用可以归属到项目、成员、模型和成本。
- 自托管部署不要求购买平台生成额度，主要生成成本随企业自己的模型 API 实际调用变化；数据库、存储、算力和运维成本仍由部署方承担。
- 节点、Adapter、模型路由、工作流和内部业务集成可以按团队需求配置或二次开发。

这不是对所有场景都更便宜的承诺，而是让账户、数据、工作流和成本控制权回到部署企业。

## 适合的场景

- 短片、广告和品牌内容的脚本与分镜生产。
- 角色、场景和道具需要持续复用的创意项目。
- 需要同时接入多个文本、图像或视频模型的团队。
- 希望把凭证、任务、资产和调用日志保留在自己基础设施中的部署者。
- 需要区分 IT 管理员、项目负责人、创作成员和只读访客的企业团队。
- 需要按项目、成员和模型追踪生成成本的运营与技术负责人。

## 已有能力

- 节点画布、列表视图和分镜表格。
- 文本、图像和视频模型 Adapter 接缝。
- Provider、渠道、凭证和模型注册表管理。
- 任务排队、轮询、取消与重试。
- 结果资产归档到远程 S3/R2 兼容存储。
- 单租户多用户、系统级与项目级 RBAC。
- 请求日志、用量和按项目 / 成员 / 模型聚合的成本观测。

## Beta 边界

当前版本不承诺稳定 API 或配置向后兼容。企业 SSO、自定义角色管理界面、实时多人协作、多租户、完整 Agent 工具循环、配额执行与生产级高可用仍在规划中。

## 开源与商业授权

XG Canvas 不拆分功能受限的社区版。完整 Beta 代码以 `AGPL-3.0-only` 发布，同时为需要专有修改、闭源集成、客户私有分支和企业支持的组织提供独立商业授权。
