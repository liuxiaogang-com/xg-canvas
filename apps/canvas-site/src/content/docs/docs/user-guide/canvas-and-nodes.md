## 节点式工作流

每个节点承担一种创意职责，例如文本、图像、视频、剧本、角色、场景、道具或分镜。节点端口具有明确类型，只有兼容的输入输出才能连接。

## 多种视图

- **画布视图**：自由编排节点和连线。
- **列表视图**：集中查看宫格或结构化内容。
- **分镜表格**：批量编辑分镜台词、提示词和时长。

## 模型参数

节点参数来自当前选择模型的参数 Schema 与约束，而不是在前端按厂商写死。切换模型后，请重新确认可用模式和参数范围。

## 保存与快照

节点和连线会持久化到后端。系统也会定期创建画布快照，用于保存阶段性状态。
